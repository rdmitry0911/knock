KNOCK CONTROL

Профили доступа

Секреты и разрешённые настройки выдаёт администратор сервера.

Добавить выданный секрет

Импортируйте выданный сервером JSON-файл. Он содержит секрет: передавайте и храните его как пароль.

Мой адрес

Сервер определяет IPv4 при запросе статуса. Если knock-пакеты идут другим маршрутом, укажите адрес вручную.

Настройки этого секрета

Загрузите настройки с сервера.

Трафик действующего соединения к защищённым портам продлевает таймаут. Knock-пакеты и обращения к API его не продлевают. Применение настроек сбрасывает разрешения только этого профиля; затем нажмите «Вкл».

Google Authenticator

Добавьте этот ключ в приложении, тип «По времени».

Ключ создан сервером. Локальный помощник хранит его в файле с правами 0600; браузер его не сохраняет.
